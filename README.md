# UC San Diego Dissertation Defense PowerPoint Template

A polished, presentation-ready PowerPoint template for doctoral dissertation defenses at UC San Diego. It combines a UCSD-inspired visual system with a clear academic narrative, smooth transitions, and an interactive Q&A workflow.

[Download the PowerPoint template](./ucsd_defense_template.pptx)

## Highlights

### UCSD-inspired theme

- UC San Diego navy-and-gold color palette
- Clean typography and consistent visual hierarchy
- Branded title, chapter, summary, acknowledgements, and closing slides
- Professional layouts designed for scientific figures, maps, equations, videos, and key findings

### Smooth presentation flow

- Coordinated transitions create a polished experience without distracting from the research
- Subtle fade transitions maintain continuity across the main presentation
- Distinct transitions help separate the closing and Q&A sections

### Well-structured defense narrative

The 26-slide template provides a complete framework for a dissertation defense:

1. Title slide
2. Introduction and research motivation
3. Dissertation chapter overview
4. Chapter background, methods, results, and summary slides
5. Ongoing and future work
6. Final summary and outlook
7. Acknowledgements
8. Thank-you and Q&A slides
9. Backup slides for detailed questions

Repeated chapter-menu slides show the audience where they are in the talk, while chapter-summary slides make the main contributions easy to remember.

### Interactive Q&A shortcuts

- A dedicated Q&A shortcut menu provides one-click access to the main chapter topics and supporting material.
- The main shortcut menu links directly to the relevant chapter entry slides.
- A small bottom-right navigation hotspot is built into the slide master, making it easy to return to the shortcut menu during Q&A.
- A separate backup-slide menu can be customized with links to additional methods, calculations, sensitivity tests, or supplementary results.

## How to use

1. Download `ucsd_defense_template.pptx` and open it in the desktop version of Microsoft PowerPoint.
2. Replace the bracketed placeholders on the title and acknowledgements slides.
3. Update the chapter titles, section labels, figures, citations, and summary statements.
4. Add or remove chapter sections as needed while preserving the recurring overview and summary pattern.
5. Customize the Q&A shortcut menus near the end of the deck and assign hyperlinks to the slides you want to reach quickly.
6. Run the presentation in Slide Show mode and test every shortcut before the defense.

> **Tip:** The bottom-right shortcut control is intentionally subtle. If you need to modify it, open **View → Slide Master** in PowerPoint.

## Recommended workflow

- Keep each slide focused on one takeaway.
- Use the chapter-summary layouts to state conclusions, not repeat results.
- Place detailed derivations, robustness checks, and extra figures after the Q&A menu.
- Test animations, embedded media, fonts, and hyperlinks on the computer that will be used for the defense.
- Export a PDF backup in case PowerPoint or embedded media is unavailable at the venue.

## Compatibility

Microsoft PowerPoint for desktop is recommended for the intended experience. GitHub and browser-based previews may not reproduce transitions, embedded media, animations, or internal slide hyperlinks; download the `.pptx` file and present it in Slide Show mode.

The repository copy uses presentation-resolution media to stay within GitHub's browser-upload limit while retaining the animated slide content.
